Our sources

Built to be checked.

Public records only

Everything comes from the City Auditor's Data Hub: purchase-order lines, invoice journals and accounting distributions. No private feeds, no API key.

One supplier, fully traced

Vendor account 002166 only, so each selected order can be followed into its invoice. It is not a total of Columbus diesel buying or a supplier comparison.

Flags, not accusations

A flag means the records differ, or a match is missing, within the loaded files. The review threshold is $25 on the full order total. No matched order crosses it.

Limits stated up front

The award (PA008056, to Sept 30, 2027) is context, not proof an order used it. No bills of lading or daily contract index, so delivery and final per-gallon charge are unverified.

Build your own view of the year.

Pick a measure, then a month. Figures cover listed PO-line dates January through October 2026. The year is in progress, so these are snapshot counts, not full-year totals.

Rebuild the numbers yourself.

Python 3 and a network connection. The script downloads the current public CSVs, rebuilds data.json and every figure on this page follows.

Open the repository 
# rebuild the data
python3 src/build_data.py

# serve it
python3 -m http.server 8000 --directory dist

# check the joins
python3 -m unittest discover -s tests -v
